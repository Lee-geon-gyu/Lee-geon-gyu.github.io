# Afternoon Atelier · 이건규 포트폴리오

UI/UX 웹 디자인 및 퍼블리싱 포트폴리오. 오후의 공방, 수영장 테라스와 2층 서재가 열린 통로와 실제 계단으로 연결된 Three.js 공간입니다.

## 공개 배포

공개 주소: https://lee-geon-gyu.github.io/

`main`에 푸시하면 `.github/workflows/deploy-pages.yml`이 의존성 설치,
React/Vite 빌드, 테스트를 실행하고 `dist/client`를 GitHub Pages에 배포합니다.
저장소 Settings → Pages의 Source는 **GitHub Actions**를 사용합니다.
소스의 `index.html` 대신 빌드된 HTML·JS·에셋이 제공됩니다.

## 둘러보기

- WASD 또는 방향키: 이동. 마우스 드래그: 시점. 파란 액자 클릭: 상세 보기.
- Shift: 달리기. Space: 바닥에서 점프, 물속에서 길게 누르면 상승.
- 발코니와 올라가는 계단 난간 위에도 점프로 올라설 수 있으며, 난간에서 Space와 이동을 함께 누르면 밖으로 뛰어내립니다.
- 수영장에 걸어 들어가면 실제 깊이로 가라앉습니다. Space를 눌러 떠오른 뒤 가장자리 방향으로 움직이면 올라옵니다. 물속의 ‘물 밖으로’ 버튼도 같은 가장자리를 따라 연속해서 이동합니다.
- Profile / Portfolio / Contact 메뉴로도 같은 내용을 확인할 수 있습니다.
- 확인한 오브젝트의 파란 표시가 사라지고 오른쪽 진행도에 반영됩니다. Portfolio 메뉴는 여섯 작업물을 모두 표시합니다.
- 다음 공간 / 이전 공간은 실제 통로를 따라 이동합니다. WASD나 드래그로 안내 이동을 취소할 수 있습니다.
- 2층 서재 / 1층 테라스는 오른쪽 계단의 중간 참과 완만한 위쪽 회전을 따라 오르내립니다. 직접 걸어서도 같은 계단을 이용할 수 있습니다.
- 왼쪽 작업실 버튼은 넓어진 앞 통로를 따라 실제 왼쪽 방으로 안내합니다. 직접 걸어 들어갈 수도 있습니다.
- 상세 화면에서는 이동을 멈춥니다. ESC 또는 닫기 버튼으로 돌아갑니다.
- 다시 시작은 위치와 진행도를 초기화합니다. 모바일에는 터치 이동 버튼이 있습니다.
- 모바일에는 달리기와 점프 / 떠오르기 버튼도 있습니다. 상세 화면, 초기화 또는 창 이탈 시 눌린 입력이 남지 않습니다.

## 개발

Node.js 20 이상에서 `npm ci`, `npm run dev`를 사용합니다. `npm test`는 콘텐츠 원본 해시, 완료 집계, 세 방향 계단 전폭의 연속 이동과 비틀린 좌표 변환, 양방향 이동과 초기화, Sites 정적 파일 제공을 검증합니다. `npm run build`는 `dist/client`와 Sites용 `dist/server`, `dist/.openai`를 생성합니다.

브라우저는 `public/assets/runtime`의 경량 모델·이미지를 사용합니다. 건축·식재
원본 생성과 조명 베이크를 끝낸 뒤 Blender에서
`--background --factory-startup --python tools/build_runtime_models.py`를 실행하고,
Pillow가 설치된 Python으로 `tools/prepare_runtime_images.py`를 실행합니다.
이 순서로 모델 내 텍스처까지 압축하고 액자 미리보기 목록을 갱신합니다.
작업물 원본과 조명 UV는 유지됩니다. 새 작업물을 추가할 때도 이미지 준비
스크립트를 다시 실행하세요. `npm test`는 모델·다운로드·화면 해상도 예산도
검사합니다. 실제 모델 광선 검사는 개발 주소의 `?geometryQA`에서만 실행하며,
일반 dev/preview 시작 시에는 수행하지 않습니다.

## 콘텐츠와 공간

- `public/portfolio-content.json`: 기존 프로필 다섯 영역, 여섯 프로젝트의 설명·메타데이터·이미지·11개 링크, 연락처 원문.
- `public/content-integrity.json`: 원본 콘텐츠 이미지 34개 SHA-256.
- `src/App.jsx`, `src/styles.css`: 로더, 메뉴, 퀘스트, 상세 화면.
- `src/navigation/`: 연속 이동, 충돌, 경로 안내, 입력 초기화.
- `src/scene/createScene.js`: PBR 재질, 햇빛과 그림자, 반사, 실제 작업물 액자, 상호작용.
- `tools/build_atelier.py`, `tools/build_vines.py`, `tools/bake_lighting.py`, `tools/denoise_lighting.py`: Blender 건축·가구·덩굴 생성과 간접광 베이크, 조명 노이즈 정리. `tools/generated`와 원본 대용량 에셋은 Git에서 제외합니다.
- `public/references/`: 승인한 공방, 수영장 테라스와 2층 연결 시안. 실제 공간은 GLB 기하 모델로 렌더링합니다.

이전 사이트의 파일과 스냅샷은 작업 당시 `Documents/Codex/2026-10-03/new-chat-2/outputs/implementation-baseline`으로 이동했고, 전체 원본 ZIP도 그 폴더에 보존했습니다.

에셋 출처는 [CREDITS.md](CREDITS.md), 시안 비교와 검증 상태는 [design-qa.md](design-qa.md)에 기록합니다.

건축 수정 후에는 독립적인 Blender `--background --factory-startup` 인스턴스에서 `build_atelier.py` → `bake_lighting.py` → `denoise_lighting.py` 순서로 실행합니다. GLB와 2048px 간접광 맵은 같은 UV 배치에서 함께 생성되므로, 두 파일이 모두 준비된 뒤 브라우저를 새로고침합니다.

1층에는 왼쪽 작업실과 정면 안쪽 공방, 두 공간이 있습니다. 두 곳 모두 수영장 앞의 열린 마른 바닥을 통해 드나들며, 왼쪽의 옛 전시벽 뒤 빈 틈과 가로막던 외벽을 정리했습니다. 안쪽 작업물 벽은 정면을 유지하고 바깥 목재 기둥·차양·발코니·난간은 약 9° 기울어진 외벽 선을 따릅니다. 참고 이미지를 3D 배경으로 사용하지 않습니다.

2026-10-06 최신 수정은 `public/references/06-three-direction-stair.png`와 같은 구도의 고해상도 `03-two-storey-atelier.png`를 기준으로 합니다. 오른쪽 계단은 아래쪽 완만한 사선 8단 → 곧은 중간 10단 → 평평한 참 → 반대 방향의 위쪽 사선 6단으로 이어집니다. 총 24개 단, 실제 높이 약 4.26m, 폭 약 2.86m입니다. 꺾이는 지점마다 계단 양쪽 모서리를 공유하는 다각형 발판을 사용합니다. 난간·석재 옆벽·화단도 같은 모서리 선을 따라 이어져 삼각형 구멍이 생기지 않습니다. 기하, 충돌과 안내 경로는 `space-layout.json`의 세 구간과 참을 공유합니다. 2층 외곽 오른쪽 벽은 뒤쪽 벽과 마당 외벽 사이를 닫고, 서재 앞 도착 통로는 열려 있습니다. 계단과 2층 바닥은 1층 야외 바닥과 같은 석재 타일 및 줄눈을 사용합니다. 수영장 옆과 앞의 넓은 통로 및 열린 왼쪽 작업실을 유지합니다.

논리적 치수에 `[1.12, 1.12, 1.06]`의 배율과 `x += z × 0.045`의 작은 공간 비틀기를 한 공통 변환으로 적용해 건축·식재·조명·물과 카메라 바닥 위치를 함께 늘립니다. 실제 1층 앞쪽 천장은 약 4.03m, 2층 바닥은 4.26m, 2층 천장은 7.56m입니다. 마당은 약 12.03×13.14m, 수영장은 약 5.15×5.67m입니다. 사람 눈높이는 실제 1.53m로 유지합니다. 담 높이 약 7.22m는 위층에서도 외부 지평선을 가리며, 하늘과 담 밖 나뭇가지가 담 위로 보입니다.

중앙 위층 천장에는 청동 갓과 따뜻한 확산판이 있는 펜던트 조명 하나를 배치했습니다. 모든 벽 구역의 청동 무드등은 `src/scene/wall-decor.json`을 런타임과 베이크에서 공유합니다. 왼쪽·끝·오른쪽 벽 아래 화단은 연속된 U자 밴드이며, 계단 옆에도 연속된 낮은 화단이 이어집니다. `garden-layout.json`의 뿌리에서 줄기·가지·잎을 생성하고 담과 발코니 가장자리까지 덩굴이 자랍니다. 일부 뿌리에서 이어진 가지가 담 위로 넘어가고, 서로 다른 분기 수·길이·방향으로 자연스럽게 흐릅니다. 발코니 난간 아래에는 두 줄의 석재 타일과 덩굴이 이어집니다. 계단 옆면은 연속된 미장 벽과 석재 모서리로 구성하며, 청동 벽등 세 개와 매입등 여덟 개가 측면과 디딤돌을 비춥니다. 별도 화분을 반복해서 붙이는 방식 대신 연결된 화단과 실제 가지 구조를 사용합니다.

석재는 미세 요철·줄눈·얇은 광택과 시점에 따른 바닥 반사를 유지합니다. 물은 푸른 산란광, 움직이는 물결과 실제 건축 반사 위에 금빛 하이라이트를 더합니다. 햇빛을 가리는 두 나무의 위치도 `garden-layout.json`을 공유합니다. 런타임과 Blender 간접광 모두 같은 식재를 사용합니다. `lighting-layout.json`에서 햇빛 방향·광량, 환경광·하늘 밝기 및 색 보정을 공유합니다. 높이를 낮춘 해, 살짝 어두운 늦은 오후의 그늘, 따뜻한 벽등·계단등·서재 조명이 함께 보이도록 맞춥니다. 모든 미장 벽은 동일한 재질과 기본 색을 사용하며 자연스러운 빛과 그림자 차이는 유지합니다.

식재와 건축을 수정한 뒤 `build_atelier.py`와 `build_vines.py`를 완료하고, `bake_lighting.py` → `denoise_lighting.py`를 실행합니다. 공개 GLB와 조명 맵을 같은 UV로 함께 생성한 뒤 브라우저를 새로고침합니다. 실제 메시에 대한 계단 전폭·평참·상층 도착 바닥의 석재 표면 검사, 계단과 왼쪽 입구·앞 통로·수영장 옆 통로의 몸 높이 광선 검사, 양방향 연속 이동, 직접/메뉴 열기의 공동 완료 집계, 다시 시작, 콘텐츠 원본 해시와 생산 빌드를 검증합니다. 생성 시안과의 사진 단위 100% 일치를 주장하지 않으며 실제 화면 비교와 남은 차이는 design-qa.md에 기록합니다.

2026-10-07에는 2층 오른쪽의 빈 옆 공간을 미장 벽체로 채우고 서재 앞쪽 도착 통로만 유지했습니다. 바깥 외벽은 `space-layout.json`의 `eastWall` 선을 따라 계단의 세 방향에 맞게 꺾이며, 아래층 정면과 계단 사이 틈도 `lowerCornerClosure`로 닫습니다. 외벽 조명과 덩굴도 같은 경계에 붙어 있습니다. 실제 모델의 외벽 맞춤 거리와 마지막 디딤돌의 타일 마감을 추가 검사합니다.

수영장 바닥은 논리 높이 -2.55m, 실제 깊이 약 2.86m입니다. 사람 발 위치와 카메라의 점프/수영 높이를 따로 적분해 입수나 탈출 시 높이가 순간 변경되지 않도록 했습니다. 육지 걷기 1.75m/s, 달리기 3.45m/s, 수영 1.25m/s이며, 물속 Space 상승과 가장자리 올라오기, 수중 색 흡수·안개·수면 아랫면을 구현했습니다. 자동 안내는 물속에서 먼저 상승하고 마른 가장자리로 올라온 뒤 기존 경로를 따라갑니다. 22개 검사는 원본 콘텐츠·기존 경로에 더해 점프 반복 방지, 잠김, 상승, 네 방향 탈출, 안내 복구·입력 초기화를 포함합니다.


2026-10-07 벽 디테일 수정: 외벽의 기본색과 미네랄 질감은 밝고 따뜻한 베이지로 통일하고, 과하게 어두웠던 북향 벽에 최소 확산광을 보정합니다. 벽등과 나뭇잎 그림자는 유지됩니다. 1층 두 작업실과 2층 서재의 모든 실내 벽은 짙은 목재 받침과 43mm 폭·35mm 간격의 실제 세로 오크 슬랫으로 마감합니다. 목재 섬유, 얇은 모서리 곡면과 보드 사이 깊이가 시점에 따라 보이고 원본 액자는 앞쪽으로 배치합니다.

오른쪽의 계단 외벽은 집 뒤까지 하나의 평면으로 이어지고 2층 바닥도 벽 안쪽에 맞춥니다. 1층 정면의 오른쪽 벽과 막힌 2층 옆 공간은 하나의 L자 단면 벽체로 만들어 별도 기둥처럼 돌출되던 겹침을 없앴습니다. 실내 마감과 식재, 충돌 영역도 같은 치수를 사용합니다. 추가 검증은 2층 바닥이 외벽 밖으로 돌출되지 않는지와 실제 로드된 벽의 평탄도를 검사합니다.
